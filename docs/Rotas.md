## Rotas 

GET/ Login // Token de autenticação 

GET /Usuario  //trazer o usuario do DB

POST /Usuario //criar um usuario no DB

PATCH /Usuario // atualiza parcialmente no DB

DELETE /Usuario // deleta no DB

GET /Fichas  //trazer a ficha do DB

GET /Fichas/:id 

POST /Fichas  //criar uma ficha no DB

PATCH /Fichas  // atualiza parcialmente no DB

DELETE /Fichas // deleta no DB

GET /Auditoria //trazer a ficha do DB

POST /Auditoria //criar uma ficha no DB

DELETE /Auditoria // deleta no DB
